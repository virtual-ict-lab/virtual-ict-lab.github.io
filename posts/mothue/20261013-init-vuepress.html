VuePress 自分流爆速構築ガイド(2026年版)

関連情報

この記事は執筆中です．今後随時更新されます．

VuePressを構築してGitHub Pagesにデプロイしたので，手順をまとめておきます．VuePressを建てたい方の参考になると幸いです．

  • 環境
  • 導入する
  • 設定と起動のテスト
  • 早速デプロイ
  • まとめ

環境

  • node v26.10.0
  • npm 11.19.1

導入する

npmで構築する場合です．my-blogの名前は好きな名前にできます．この名前で新規ディレクトリが作成されます．

GitHub Pagesで公開する場合，ここはyour-github-id.github.ioにするといいでしょう．

Bash
npm init vuepress my-blog

実行すると，何件か質問があります．迷いそうなところだけ挙げておきます：

  • Which bundler do you want to use? -> viteがおすすめです．
  • What type of project do you want to create? -> ここではblogを選びます．
  • Your project name -> 私はディレクトリ名とおなじにしています．良いのか悪いのかはわかりません
  • Do you need a GitHub workflow to deploy docs on GitHub pages? -> Y を選びます．

完了すると，依存関係などのインストールが始まるので，ちょっと待ちます．

Successful Generated!が出たら完璧です．

Would you like to preview template now?は．Yでテンプレートサーバーが動きますが，ここではnでスキップしましょう．どうせあとで開きます．

設定と起動のテスト

先ほど作ったディレクトリに移動してください． ちなみに，もしvulnerabilitiesの警告が出た場合，npm audit fix --forceをしておきましょう．

Bash
cd my-blog
npm audit fix --force

起動するかのテストをします．何も触っていなければ起動するはずです！

開発用のホットリロード対応なviteサーバーが生えてきます：

Bash
npm run docs:dev

純粋にビルドが通るだけの確認はこちら：

Bash
npm run docs:build

早速デプロイ

いよいよデプロイです．まず，このリポジトリをGitHubにアップロードしてください．すると，workflowsの中のCI/CDが走って，自動でビルドされます．

変なことをしていない限り，問題は起こらない（はず）です．問題が起きたらClaudeとかに聞いてください．

CIが通ると，こんな感じに緑のチェックマークが出てきます．

ビルド通らなかった場合，赤色の❌表示になるので，クリックするとログが見れます．

次に，GitHubの設定を開きます：

Settings -> Pages -> Branchから，"Branch"の項目を開きます．

ここの"Branch"が，デフォルトではmainになっていると思うので，ここをgh-pagesにします．これで公開ができるようになるので，保存してから数分待つと，設定したドメイン（特にいじっていないならyour-github-id.github.ioになっているはず）でアクセスができます．

まとめ

GitHub Pagesは神！なので全人類GitHub Pagesでオリジナルのブログを生やしましょう．
